# 시트 연결 (10분)

1. Google 스프레드시트 새로 만들기 → 주소의 `/d/<ID>/` 복사
2. 확장 프로그램 → Apps Script → `scripts/apps-script.gs` 내용 붙여넣기, `SHEET_ID`·`NOTIFY_TO` 채우기
3. 배포 → 새 배포 → 유형 「웹 앱」 · 실행: 나 · 액세스: **모든 사용자** → 웹앱 URL 복사
4. `data/config.js` 의 `SUBMIT_ENDPOINT` 에 붙여넣기 → 커밋·푸시
5. `wishes.html` 에서 의뢰 하나 올려 보고 목록에 뜨면 끝

## 탭 (자동 생성)
| 탭 | 어디서 | 할 일 |
|---|---|---|
| 접수 | 내 장소 등록하기 | 검수 → places.js 에 옮겨 적기 |
| 삭제요청 | 내려 주세요 | **먼저 내리고** 나중에 확인 |
| 신고 | 안 열려요 | 접속 확인 → 닫혔으면 내리기 |
| 문의 | 공간 제작 문의 | 하루 안에 메일 회신, 「상태」 갱신 |
| 의뢰 | 이런 장소 있었으면(게시판) | 자동 공개. 문제 글은 「숨김」 열에 `Y` |

- 모든 폼이 같은 URL 로 가고 `kind` 로 탭이 갈린다. 게시판 목록은 같은 URL 에 `?list=wishes` GET
- 의뢰 글은 4~80자, URL 포함 불가(스크립트에서 거름). 투표는 기기당 1회(localStorage) + 시트 +1
- 등록·문의 폼은 `mode:"no-cors"` 라 응답은 못 읽지만 행은 들어간다
- 스크립트를 고치면 「배포 관리 → 새 버전」을 해야 URL 에 반영된다
